# Patchwork

Offline, voice-first daily journal for Indian languages + English.

## What it is

Speak a short voice note every day — a moment, a thought, a feeling. Audio is
stored on the device only (no server, no login, no tracking). Each week you
get a recap: entries count, streak, average mood, and the words you mentioned.

## Run

```bash
npm install
npm start
```

or `npm run ios` / `npm run android` / `npm run web`.

## Tests

```bash
npm test
```
